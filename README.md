# GUI_Extension

底部 HUD 重制。把原版那两条「生命条 / 精力条」重新分配，再加一个日期时间和可选的敌人血条。
所有功能都能在游戏内 **ESC → 设置 → MODS → GUI_Extension** 里单独开关，关掉即回到原版外观。

- 作者：Pixel32E
- 版本：v1.17.0.0
- 平台：Stoneshard（ModShardLauncher）
- 界面语言：中文 / English / Русский / 日本語 / 한국어（设置项本身也会跟着游戏语言变）

## 布局

```
[斗志容器 x=138] [ 生命条 158px ] [ 精力 83 | 格挡 83 ] [神智容器 x=498]
```

左槽（原生命槽，158px）整条给生命；右槽（原精力槽，167px）由精力和格挡力量各占 50%；
斗志、神智做成两根 22×46 的圆柱液体容器，立在面板两端。

## 功能

### 1. 生命条（左槽 158px）

原版整条横条样式（阈值残段 + 掉血残影 + 居中 `当前/上限`），和原版完全一致，只是槽位独占。

悬停（原版生命悬停区，内容已换）可看到：

- 标题：`生命 118/155`（当前 / 有效上限；低于 50% 标题转红）
- 正文首行：`155 / 170 (-9%)` —— 只有上限**确实被伤势压过**时才出现
- 之后是原版的生命属性说明（含恢复回合数的占位符替换）

### 2. 斗志 / 神智容器（面板两端）

底部面板左端（面板内 x=138）与右端（x=498）各立一根 22×46 的圆柱液体容器，液面高度 = 属性百分比，
条上印 0–100 的数值，**低于 50 整根换成红色液体**（复用生命容器配色）。

两根各有独立悬停：属性说明里的 `Morale*Situational/Diet/Rest`、`Sanity*Situational/Rest/Lifestyle` 占位符会按面板同一套算法填上数值。

### 3. 精力条（右槽左半 83px）

横条样式（原版精力配色 + 掉值残影 + 居中 `当前/上限`）。悬停显示 `精力 82/83`，
上限被**疲劳**压低时多一行 `有效 / 原始 (-x%)`。

### 4. 格挡力量条（右槽右半 83px）

橙色分层条（描边 / 高光 / 主体 / 暗部 / 描边），带掉值残影（掉格挡后亮色拖尾 0.2 速度收回）。
悬停显示格挡力量的属性说明 + 格挡几率。

### 5. 日期时间（右下角）

屏幕右下角显示 `3 天 14:35`：总天数 + 24 小时制时间（分钟补零），右对齐、距右 6px、距底 4px，字号 0.65。

### 6. 敌人头顶血条

敌人头顶 26×6 的小血条：1px 黑边 + 4px 纵向渐变，**按血量比例三档变色**（>60% 绿 / 30~60% 黄 / <30% 红）。

- 默认**只在鼠标悬浮该敌人时**显示
- 勾选「敌人血条常显」后常显
- 自动过滤：训练假人、不可见、已死亡、UI 关闭、施法瞄准中、过场动画、鼠标停在 GUI 上

## MODS 设置项

| 键（msl_menu_mod.ini → `[GUI_Extension]`） | 默认 | 作用 |
|---|---|---|
| `msl_gui_ext_prr_on_bar` | 关 | 格挡条上的数字是否附带格挡几率 |
| `msl_gui_ext_show_psy` | 开 | 斗志/神智两根容器；关掉就只剩原版生命条 |
| `msl_gui_ext_show_bp` | 开 | 精力 50% + 格挡 50%；关掉恢复原版整条精力条 |
| `msl_gui_ext_show_clock` | 开 | 右下角日期时间 |
| `msl_gui_ext_enemyhp_always` | 关 | 敌人血条常显（关 = 仅悬浮） |

设置项文本走 `scr_msl_gui_ext_tr`，在 `o_checkbox` 绘制前翻译，目前提供中/英/俄/日/韩，其它语言回退英文。

## 已知限制

- **神智容器与技能格**：容器 22px 宽、面板内 x=498，与第 10 格技能格（479–504）有 6px 水平重叠；两者同深度、技能格创建更晚，会盖住容器左边一小条。想要完全不碰就把它右移到 504 以外。
- **敌人血条遮挡**：画在 `o_enemy` 的 Draw End 里，深度等于敌人自身，可能被树干、墙角等前景挡住。
- **精力/格挡条数字**：格子只有 83px，勾选「格挡条显示几率」后 `11/11/20%` 会比较挤。
- **旧的 ini 键**：`msl_gui_ext_show_prr` 是早期测试用的键名，现已被 `msl_gui_ext_prr_on_bar` 取代，旧行留着也无副作用。
